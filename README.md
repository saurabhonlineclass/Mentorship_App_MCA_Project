# Smart Study Planner with Mentorship System for Competitive Examinations 🎓

A web-based study management platform designed to help competitive examination aspirants organize their study schedules, improve focus, track progress, and receive mentorship and AI-assisted learning support.

## ✨ Features

- 📚 **Study Task Planner** – Organize and manage daily study tasks.
- ⏱️ **Focus Timer** – Track study sessions and improve concentration.
- 🎯 **Mentorship System** – Support structured preparation with study guidance.
- 🤖 **AI Chatbot** – Provide AI-assisted learning support and study suggestions.
- 📰 **Current Affairs** – Access current affairs resources for exam preparation.
- 📊 **Progress Tracking** – Monitor study activities, task completion, and productivity.
- 🔐 **User Authentication** – Manage access to the application securely.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **AI Integration:** OpenAI GPT API
- **Development Environment:** Visual Studio Code
- **Version Control:** Git and GitHub

## 🎯 Project Objective

The main objective is to provide a centralized platform for competitive exam aspirants preparing for examinations such as UPSC, PCS, SSC, Banking, and Railway. It combines study planning, time management, mentorship, and performance monitoring in one application.

## 🚀 Future Scope

- Personalized study recommendations
- Advanced analytics and performance reports
- Enhanced revision and calendar management
- Additional mentorship and learning features
